# v1.4.0 — локальный NDEF Type 4 без Pixel

Полный релиз для **Mi Smart Band 10 Pro Ceramic Global** (`miwear.watch.p67glt`),
прошивка **3.201.026**. Аппаратная приёмка нового режима выполняется пользователем
по [чеклисту](../local-ndef-acceptance.md); host-тесты релиза пройдены.

## Что нового

- **Локальный ответчик NFC Forum Type 4 NDEF на браслете.** После синхронизации
  каталога браслет сам отвечает на SELECT/READ BINARY; Pixel в момент чтения не нужен.
- **UI5**: сеанс стартует при открытии страницы «NFC-метки», останавливается при
  уходе/паузе и по таймауту 60 секунд. Бейдж показывает `NDEF` → `NFC…` → `NFC`,
  при ошибке — `Ошибка`.
- Смена записи сначала останавливает NFC; каталог и выбор переживают перезагрузку.
- Новый циферблат **Roundabout RU NFC Local**, Face ID `999999969`; старые
  циферблаты и core/UI не перезаписываются.
- Синхронизация — существующим APK Tag Bridge **0.4.1**.

## Установка

1. Передать `roundabout-ru-nfc-local-p67glt.face` через Notify for Xiaomi и
   выбрать **Roundabout RU NFC Local**. Face ID новый, поэтому установка
   отдельная.
2. Перезагрузить браслет. Один раз нажать нижний круг: модули загрузятся,
   браслет перезагрузится.
3. Синхронизировать каталог с Pixel при **закрытой** странице «NFC-метки»
   (при открытой странице локальный NFC уже активен).
4. Открыть «NFC-метки», выбрать запись, выключить Pixel/Bluetooth и приложить
   браслет к NFC-считывателю.

Подробные шаги, граничные случаи и форма отчёта — в
[чеклисте приёмки](../local-ndef-acceptance.md).

## Ограничения

- Нет Mir Pay, банковских карт, транспорта, UID/eSE и RF-пробуждения.
- NDEF-содержимое публично, пока сеанс активен.
- Только точная модель и прошивка `3.201.026`.
- Автозагрузка зависит от установленного циферблата.
- Аппаратная приёмка ещё должна быть выполнена; host-тесты не заменяют её.
