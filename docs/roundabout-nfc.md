# Roundabout RU NFC

Отдельная версия Roundabout RU с входом в экран **«NFC-метки»** через нижнюю круглую кнопку. Модель — `miwear.watch.p67glt`, прошивка — **3.201.026**. Исходный Roundabout и сохранённый Roundabout RU (`999999995`) не заменяются; новая копия получает ID `999999994`, установщик — `999999993`.

## Статус

На браслете подтверждены регистрация `NFC_TAGS_UI1 / READY / 0 / END`, открытие страницы нижним кругом Roundabout и отображение `NFC-Test` после обновления. С активным экраном получены `QUERY #1446798741 → STOPPED` и `#1446798742 → TAG_OK`: core продолжает работать после смены циферблата. [Отчёт проверки](evidence/tags/roundabout-nfc-v1-hardware.json).

В установленном UI v1 пользователь обнаружил наложения текста и отсутствие прокрутки. Причина тесной раскладки найдена: исходный нативный стиль использует шрифт **40 px**. Кандидат UI v2 с автоматической высотой и прокруткой собран и прошёл host-проверки, но **не установлен**. Затем пользователь выбрал компактный экран без прокрутки и попросил сначала визуализировать его. Сейчас следующий UI представлен макетом; каталог из нескольких меток и кнопки переключения ещё не реализованы. [Требования к экрану и каталогу](technical-spec.md).

Ранее подтверждённый NDEF PASS относится к APK 0.3 + FACE v2. В проверке нового входа NFC не запускался; физический NDEF-readback повторно не выполнялся. Сборки и исходные артефакты сохранены отдельно в [releases/roundabout-nfc](../releases/roundabout-nfc/manifest.json).

## Поведение

- Нижний круг новой копии закреплён за «NFC-метки». Две верхние кнопки и живые показатели циферблата сохраняются.
- Открывается отдельная native-страница с последней выбранной на Pixel записью. Она вызывается из круга, отдельная иконка в общем меню приложений не добавляется. Выбор из каталога остаётся на Pixel; обновление отображения — вручную на странице.
- Открытие страницы не запускает NFC. START/STOP остаются в приложении **«Метки · NFC»** на Pixel. Закрытие страницы само по себе также не отправляет STOP в неизменённый core v2.
- Модули остаются в памяти до перезагрузки браслета. После перезагрузки нужно повторить установку с setup-циферблата и вернуться на Roundabout RU NFC.
- Пробуждение от NFC-поля не реализуется; оно остаётся отдельным пунктом [ТЗ](technical-spec.md). Новый UI не требует постоянного таймера обновления или удержания экрана включённым.

## Устройство интеграции

В compiled Widget Roundabout есть собственный байт действия, который передаётся в диспетчер приложений. Это другой путь, чем общий `jump_app` с таблицей 39 строк. Native-страница регистрируется под новым ID `0xD4`, если ID свободен; кнопка адресует именно её. Штатные приложения, таблица строковых действий и код прошивки не подменяются.

Установщик содержит два независимых ELF: проверенный core v2 и новый модуль UI. Core сохраняется побайтно; второй ELF занимает прежний неиспользуемый слот картинки `recorder.bin` на 9841 байт. Длины записей, смещения и общий размер installer FACE остаются прежними. Оригинальные Lua и executable payload заменяются; прочие изображения шаблона сохраняются.

`tags/build_launcher_face.py` проверяет хеш core, формат и constructor UI ELF, пределы слотов, все записи и отсутствие изменений вне разрешённых областей. До `insmod` Lua сохраняет временный guard; неоднозначная ошибка загрузки или записи финального marker требует перезагрузки, а не повторной загрузки резидентного модуля.

Файл `/tmp/tag_catalog_state` содержит последнее опубликованное состояние. Оно не доказывает, что BLE прямо сейчас подключён. UI должен отклонять неполную запись вместо отображения частично записанных полей.

## Проверка на браслете

1. Начать после перезагрузки, чтобы не смешивать версии резидентных модулей. Загрузить core и UI новым установщиком; проверить диагностический READY.
2. Выбрать Roundabout RU NFC. Нажать нижний круг: должна открыться страница «NFC-метки». Проверить выбранную запись, обновление и возврат назад.
3. Повторить открытие/возврат; часы и две верхние кнопки должны продолжать работать.
4. На Pixel подтвердить `QUERY → STOPPED` после смены циферблата. Проверить синхронизацию метаданных и обновление страницы.
5. Проверить NDEF-readback с новой страницей; после прогона подтвердить STOP и повторный QUERY. Не переносить прежний PASS на новую конфигурацию без измерения.
6. Перезагрузить браслет и проверить повторную регистрацию без конфликта ID и автоматического запуска NFC.

Сохранённые APK 0.3, FACE v2 и обычный Roundabout RU остаются отдельными исходными точками для сравнения.
