# Tag Bridge 0.4.1

Карточки увеличены. Справа две кнопки 48×48 dp с радиусом 12 dp: меню «⋮» сверху, чекбокс передачи ниже. Отмеченный чекбокс голубой с галочкой. Счётчик показывает число отмеченных записей.

Синхронизация отправляет только отмеченные записи и заменяет ими каталог браслета. Все записи остаются на Pixel. Отметки сохраняются; выбор карточки для NFC независим. Новые записи не отмечены, старые записи без поля syncToBand сохраняют прежнее включение. Пустая синхронизация спрашивает подтверждение перед очисткой непустого каталога браслета.

Проверено: 615 JVM-проверок и 16 инструментальных проверок настоящих Android JSON/AtomicFile и передаваемого снимка. Приложение установлено на Pixel 8a. Повторный аппаратный NFC/BLE прогон нового каталога в эту проверку интерфейса не входил.
