# Tag Bridge 0.4 — интерфейс Pixel

Установлен на Pixel 8a 13 ноября 2026 года поверх предыдущей версии с сохранением каталога.

- Чёрная тема, компактные карточки меток, выделение выбранной записи.
- «Добавить метку»: считать NFC либо создать текст/ссылку.
- Меню каждой карточки: сведения, переименование, удаление. UID находится в сведениях.
- BLE открывает отдельное окно сопряжённых устройств и ввода адреса. Последний адрес запоминается.
- «Запустить Debug» открывает журнал и команды диагностики; само открытие NFC не запускает.
- Адаптивная и монохромная иконки для Pixel Launcher.

Окна реализованы как полноэкранные Android Dialog в текущей Activity: открытие окна не переводит обработчик BLE/NFC в фон. Закрытие активной NFC-проверки запрашивает STOP. Фоновая эмуляция не добавлена.

## Проверка

615 JVM-проверок, сборка, подпись и выравнивание APK прошли. На Pixel проверены главный экран, открытие/закрытие BLE и Debug, системные отступы. После обновления все три исходные записи сохранены. Данные меток и скриншоты с ними в релиз не включены.

Это Android 0.4 с новым протоколом CATALOG_V1. Полный аппаратный прогон нового каталога с новым модулем браслета здесь не заявлен; сохранённый NFC PASS относится к APK 0.3 + модулю v2. Для нового протокола требуется соответствующий модуль каталога.

Сборка: `python3 tags/android/build.py`. APK и исходные хеши — в `manifest.json`, контрольная сумма — в `SHA256SUMS`.
