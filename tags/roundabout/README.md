# Roundabout RU

Отдельная русифицированная копия пользовательского **Roundabout 1.1.20** для P67, 336×480. Имя новой копии — **Roundabout RU**, ID — **999999995**; оригинальный пакет `120917397222` сохраняется. Проверенный файл сборки — `build/roundabout-ru.face`; точный размер и SHA-256 записаны в [отчёте упаковки](pack_validation.json). Аппаратная проверка установки фиксируется отдельно.

Изменены **111 PNG-ресурсов** и четыре встроенные миниатюры галереи:

- 80 подписей `Steps → Шаги`, `Heart rate → ЧСС`, `Calories → Ккал`, `Activity time → Активность`, `Standing → Стоя`: обе нижние позиции, все четыре оформления и AOD;
- 29 уникальных картинок дней недели: `ПН, ВТ, СР, ЧТ, ПТ, СБ, ВС`;
- 2 варианта суффикса длительности сна: `h → ч.`.

В данных `dateWeek` Sunday находится под индексом 0, поэтому физический порядок ресурсов — **ВС, ПН, ВТ, СР, ЧТ, ПТ, СБ**. Перестановка этого массива на Monday-first показывала бы неправильный день. Покрыты все пять массивов дней; источников названий месяцев в этом циферблате нет, статические фоны календаря содержат только иконки. Число месяца и числовые значения сна, шагов и пульса не менялись.

Сохранены размеры изображений, отдельные иконки рядом с нижними подписями, геометрия циферблата, источники данных, все варианты трёх круглых кнопок и действия `jumpApp`. Русские глифы встроены в PNG, наличие кириллицы в системном шрифте браслета не требуется. Сокращение «Ккал» сохраняет читаемый размер: полное «Калории» требовало слишком мелких букв в прежней наклонной ячейке. Международные AM/PM оставлены; это растровые обозначения рядом с восходом/закатом в основной фоновой картинке, а не календарные строки.

Новый пункт «NFC-метки» в круглых кнопках пока не добавлен: причина и конкретный план описаны в [исследовании интерфейса](../ui-research/README.md). Русификация не добавляет такой функции.

Цветовые варианты NFC 5 (девять отдельных `.face`, поскольку формат держит
4 стиля + 4 AOD) описаны в [THEMES.md](THEMES.md); там же сборка, палитры и
ограничения.

## Повторить подготовку

Нужны Python и Pillow; использован Pillow 11.3.0. Скрипт по умолчанию берёт локальный macOS Arial Bold с кириллицей. Сам шрифт не включён в проект; точный хеш использованного файла записан в `localization-map.json`. Для другой платформы передайте свой TTF через `--font`.

```sh
python3 tags/roundabout/localize.py \
  references/roundabout-original.zip build/roundabout-ru-source --source-zip \
  --report tags/roundabout/localization-map.json \
  --preview build/roundabout-ru-assets-preview.png

python3 tags/roundabout/render_previews.py \
  build/roundabout-input-ef28f7054966 build/roundabout-ru-source \
  build/roundabout-ru-preview.png

python3 tags/roundabout/pack_roundabout.py \
  --original build/roundabout-input-ef28f7054966 \
  --localized build/roundabout-ru-source \
  --map tags/roundabout/localization-map.json \
  --previews build/roundabout-ru-preview-thumbnails \
  --output build/roundabout-ru.face \
  --report tags/roundabout/pack_validation.json
```

Каталог результата должен быть новым. Скрипт не перезаписывает прошлый результат и не меняет исходный кеш. Минимальные оригинальные входные данные сохранены в `references/roundabout-original.zip` (1 685 415 байт, 117 файлов, SHA-256 `ef28f70549660bc5f8a126c6e4dbcc53e13511d222863e405eade28b03766738`); архив и каждый файл описаны в `references/roundabout-original.provenance.json`, без путей аккаунта пользователя. Внутри исходный `resource.bin`, метаданные и 111 изменяемых картинок. Остальные кадры и исходные миниатюры сохраняются внутри `resource.bin`. Этот архив позволяет повторить работу после удаления ignored build-кеша. Режим `--source-zip` проверяет пути ZIP и распаковывает оригинал в отдельный ignored каталог, названный по хешу архива.

Полный пользовательский кеш остаётся в ignored `build/roundabout-source`. В изменённую source-копию намеренно не переносится старый `resource.bin`, чтобы оригинальная английская сборка не выглядела русифицированной. Для входа полным каталогом вместо архива уберите `--source-zip` и укажите путь к нему.

`localization-map.json` фиксирует каждый путь, перевод, размеры, контрольные суммы до/после, область текста и цвет. Подготовка проверяет, что изменённые кадры помещаются в палитру indexed8; иконки вне текстовых областей сохраняются попиксельно. Данные manifest/editor отличаются только именем и ID новой копии; структура макета и действий проверена сравнением.

Превью `roundabout-ru-preview.png` показывает первый стиль; `roundabout-ru-preview-styles.png` — четыре оформления. Это офлайн-рендер из исходных **скомпилированных** миниатюр, **не** фотография результата на браслете. Изменяются только пиксели переводимых подписей, ближайшие цвета выбираются из прежней палитры без dithering; цифры, дуги и иконки вне этих областей сохраняются попиксельно. Светлый четвёртый стиль использует свой белый фон. Четыре отдельные PNG и доказательства сравнения сохраняются в `build/roundabout-ru-preview-thumbnails`, затем включаются в `.face`. Остальные изменённые подписи показаны в сравнении ассетов `roundabout-ru-assets-preview.png`.

Упаковщик добавляет новые indexed8 BGRA/RLE-кадры в конец бинарного файла и меняет только указатели/размеры затронутых ресурсов, указатели миниатюр, отдельный ID и блок переведённого названия на всех 33 языках. 2343 записи неизменённых ресурсов, исходные payload и все описания макета и действий сохранены. Каждый новый кадр декодирован обратно и попиксельно совпал с подготовленным PNG. Подробности формата — [pack_README.md](pack_README.md), результаты — `pack_validation.json`. Установка и чтение подписей на реальном браслете остаются отдельным аппаратным шагом.
