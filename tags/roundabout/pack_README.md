# Roundabout RU: упаковка ресурсов

`pack_roundabout.py` создаёт отдельную русифицированную копию пользовательского
Roundabout: имя **Roundabout RU**, ID **999999995**. Оригинальный ID —
`120917397222`. Оригинальные файлы не изменяются.

Это узкий упаковщик для конкретного проверенного `resource.bin`, а не универсальный
компилятор Xiaomi. Он проверяет SHA-256 оригинала, ID ресурсов через `uidmap.map`,
изменения исходников по `localization-map.json` и размеры каждого изображения.
Требуется Python 3.9+ и Pillow. Исходники для воспроизведения находятся в архиве
`references/roundabout-original.zip`. Для чистого рабочего каталога:

```sh
python3 -m zipfile -e references/roundabout-original.zip build/roundabout-source
build/roundabout-research-venv/bin/python tags/roundabout/localize.py \
  build/roundabout-source build/roundabout-ru-source \
  --report tags/roundabout/localization-map.json \
  --preview build/roundabout-ru-assets.png
build/roundabout-research-venv/bin/python tags/roundabout/render_previews.py \
  build/roundabout-source build/roundabout-ru-source build/roundabout-ru-preview.png
build/roundabout-research-venv/bin/python tags/roundabout/pack_test.py
build/roundabout-research-venv/bin/python tags/roundabout/pack_roundabout.py
```

Результат: `build/roundabout-ru.face`. Проверки и хеши записываются в
`tags/roundabout/pack_validation.json`. Сборка выполняется детерминированно.
Установка и отображение на браслете проверяются отдельно: офлайн-проверки не
подтверждают принятие файла прошивкой.

## Что меняется

Русифицированы текстовые PNG: подписи показателей, дни недели, сокращение единицы
сна. Точные количества PNG, кадров и ресурсов указаны в `pack_validation.json`.
Их новые payload добавляются в конец оригинального файла. У неизменённых кадров
в тех же массивах сохраняются исходные сжатые байты.

В исходной части бинарника изменяются только поле ID (64 байта), указатель/размер
блока названия, указатели/размеры заменённых изображений в индексах ресурсов и
пять указателей четырёх встроенных миниатюр (основная миниатюра совпадает с первой).
Название во всех 33 локалях — `Roundabout RU`. Старые payload остаются на своих
местах; действие кнопок, разметка, стили, AOD, данные компонентов и остальные
ресурсы не переписываются. В дескрипторах меняются только указатели миниатюр.
Скрипт проверяет допустимые изменения каждого байта.

Новые изображения кодируются без потерь в indexed8 с палитрой BGRA и RLE.
Декодирование каждого нового кадра должно дать точные RGBA-пиксели локализованного
PNG. В оригинальных ресурсах обнаружена небольшая квантизация относительно PNG
(RGB до 5 уровней, alpha до 1); это допускается только при сверке соответствия
старого кадра исходнику. Новые кадры не квантизуются упаковщиком: палитра свыше
256 цветов вызывает ошибку.

Четыре встроенные миниатюры создаются из декодированных оригинальных миниатюр.
У новых глифов цвета приближаются к исходной палитре. Каждый пиксель за пределами
старых/новых глифов должен точно совпасть с оригинальным compiled thumbnail:
цифры, значки, дуги и положения элементов не меняются. Это отдельная проверка,
помимо точного RGBA-декодирования нового сжатого кадра. Миниатюры AOD не добавляются.

## Формат и границы применимости

У этого файла заголовок 168 байт, восемь дескрипторов по 176 байт и индексные
элементы `<id, reserved, absolute_offset, size>` по 16 байт. Одиночные изображения
имеют тип 2, массивы — тип 3. Сжатый кадр начинается с `e0 21 a5 5a`, после
декодирования содержит 1024 байта палитры и по одному индексу на пиксель.

Публичные исходники, использованные для сверки семейства форматов:
[Mi-Create](https://github.com/ooflet/Mi-Create),
[miband9-face-packer](https://github.com/brigealong/miband9-face-packer),
[xiaomi_band_tools](https://github.com/redkage/xiaomi_band_tools).
Конкретные параметры Roundabout, цветовой порядок и структуры подтверждены
непосредственно сравнением пользовательского бинарника с его PNG/manifest.
Код декомпиляторов в проект не включён. Упаковщик не изменяет прошивку и не
добавляет приложение NFC-меток в системное меню или компоненты циферблата.
