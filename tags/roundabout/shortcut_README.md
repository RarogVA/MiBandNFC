# Roundabout RU NFC

Отдельная копия `Roundabout RU` с нижней круглой кнопкой «Метки». Она открывает зарегистрированное native-приложение `dev.mbapdu.tags`, app ID **0xD4**, через штатный обработчик Widget. Новый ID циферблата — **999999994**; базовый `Roundabout RU` с ID `999999995` остаётся неизменным.

Циферблат остаётся декларативным: часы, стрелки, дата, метрики, остальные два круга и выбор их вариантов сохраняются. Нижний круг фиксирован на одном варианте во всех четырёх оформлениях и связанных AOD. Нажатие только открывает приложение; NFC не включается самим циферблатом. Ресурсы не меняют ROM, системную таблицу действий или ID штатного приложения.

Это **собранный кандидат со статической проверкой**, а не подтверждение запуска на браслете. Для открытия нужно сначала зарегистрировать native-модуль из `tags/launcher`. Регистрация временная, до перезагрузки. После перезагрузки потребуется повторный запуск установщика; сам циферблат остаётся сохранён. Вызов по отсутствующему app ID ещё нужно проверить на устройстве вместе с Back и повторным открытием.

## Почему работает путь запуска

На точной прошивке **p67glt 3.201.026** найдены два разных механизма. У общего eventbus-обработчика `jump_app` есть таблица 39 имён. Обычная кнопка `Widget` использует другой обработчик, `image_click_cb`, поэтому ограничения той таблицы здесь не применяются.

| Участок | Подтверждение из прошивки |
|---|---|
| `0x2c7d470a..0x2c7d4716` | Loader берёт `u16` по offset `0x2a` Widget, сдвигает на 4 и переносит 8 бит в runtime flags, биты 7..14. |
| `0x2c7d0f44` | Click handler извлекает эти 8 бит как action/app ID. Значение `0xff` выделено для строкового пути; оно не используется. |
| `0x2c4512d4` | Prelaunch helper этой прошивки всегда возвращает 0. |
| `0x2c45148c` | ID mapper меняет только `0x39 → 0x44`; для `0xD4` возвращает исходный ID. |
| `0x2c7d1042` | Native ID записывается в `u16` launch descriptor по offset `+6`. |
| `0x2c7d1066..0x2c7d106c` | Вызов штатного activity manager: function pointer `[0x200b7360+8]`. |

Дескриптор размером `0x2c` обнуляется, получает kind `9` по `+8` и обычные callback `0x0c787ee5`/`0x0c787f75` по `+0x14`/`+0x20`. Это тот же путь, которым исходный Widget запускает штатное приложение. В новой записи `u16@42 = 0x1d47`: исходные флаги сохранены, action заменён на `0xD4`. Перехват событий, overlay и постоянный таймер для кнопки не нужны.

Slot разбирается отдельно (`0x2c7d4a88`): `u8@0` — число вариантов, `u16@2` — флаги. Сохранённый trailer `04 00 00 00 33 00 00 00` является длиной и строкой группы `3`, а не выбранным индексом. Код `0x2c7d4cb4..0x2c7d4cd4` копирует строку в runtime Slot. Проверка числа вариантов допускает 1; новый Slot содержит только новый Widget и сохраняет группу.

Полные адреса относятся исключительно к SHA-256 прошивки `66701c11073aebbd1d925cb6e097aa56a3101fc747d9f0fc280cd250dce72a40`. Сборщик требует этот отпечаток. Вывод о маршрутизации основан на статическом разборе; аппаратная проверка должна подтвердить весь путь.

## Сборка и проверки

Нужны Python и Pillow (использован 11.3.0). Все восемь маленьких PNG уже сохранены в `shortcut-assets`; для обычной сборки системный шрифт не нужен.

```sh
python3 tags/roundabout/shortcut_build.py
```

По умолчанию используются `releases/roundabout/roundabout-ru-p67glt.face`, `references/roundabout-original.zip` и `references/vela_ap.bin`; каждый проверяется по SHA-256. Результат: `build/roundabout-ru-nfc.face`, отдельное превью и панорама четырёх оформлений. Отчёт — `shortcut_validation.json`. Установка на устройство скриптом не выполняется.

Добавлены 24 ресурса: отдельные изображение, перевод имени и Widget для восьми тем. В восьми нижних Slot оставлен единственный новый вариант. Прочие **2440** исходных записей индекса сохраняют свои offset/size и точные payload bytes. Изначальные bytes всех ресурсов остаются в файле; новые payloads и таблицы добавлены в конец. Проверяется whitelist изменений исходного префикса: ID, имя, нужные таблицы, восемь Slot-ссылок и указатели четырёх превью. Галерейные превью изменяются только в прямоугольнике нижнего круга `(126,274)..(210,358)`; остальные пиксели сравниваются точно.

Картинка нового круга содержит карту, значок бесконтактного обмена и «Метки». Live-ресурс упакован в indexed8 RLE с точным RGBA roundtrip. Только новая графика квантизована до 256 цветов; галерейная миниатюра использует исходную палитру. Для её регенерации на macOS:

```sh
python3 tags/roundabout/shortcut_build.py --generate-assets \
  --font '/System/Library/Fonts/Supplemental/Arial Bold.ttf'
```

`shortcut-assets/provenance.json` фиксирует шрифт и SHA-256 исходных PNG. Это воспроизводимый input для сборки, не замена живого циферблата статичной картинкой.

## Аппаратная проверка

1. Установить модуль `NFC-метки` и убедиться, что его app ID `0xD4` зарегистрирован без конфликта.
2. Установить эту отдельную копию циферблата и нажать нижний круг. Должен открыться экран приложения, сохранившись возможность возврата назад.
3. Проверить повторное открытие, смену четырёх оформлений, обновление времени/метрик и настройку двух остальных кругов.
4. Проверить AOD и пробуждение. После перезагрузки повторно зарегистрировать модуль и проверить кнопку снова.

Поддержка левого системного виджета — отдельная задача: этот вариант создаёт вход из циферблата и не вызывает неразобранный `widgets_add`.
